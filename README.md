# خريطة صناعة الإعلانات · The Ad Industry Map

دليل تفاعلي (عربي / English) لأدوار صناعة الإعلانات في مصر: الوكالة الإعلانية، شركة الإنتاج، شركة ما بعد الإنتاج، الاختصارات اللي بتظهر في الـ credits، طرق الدخول، واختبار سريع.

An interactive bilingual guide to advertising industry roles in Egypt: the creative agency, the production house, the post house, the abbreviations you meet in campaign credits, career paths, and a short quiz.

Single file, no build step: open `index.html` or enable GitHub Pages.
